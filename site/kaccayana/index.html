Gramática de KaccāyanaKaccāyana's grammar

Kaccāyana-Byākaraṇaṃ

La más antigua de las gramáticas pāḷi conservadas. Ocho capítulos (kappa), cada uno dividido en secciones (kaṇḍa). Edición base de esta traducción: Kaccāyana-byākaraṇa, ed. y trad. Bhikkhu Nandisena.The oldest of the surviving Pāḷi grammars. Eight chapters (kappa), each divided into sections (kaṇḍa). Base edition of this translation: Kaccāyana-byākaraṇa, ed. and trans. Bhikkhu Nandisena.

Sobre la numeraciónAbout the numbering

Cada sutta lleva tres números, como en la edición de Nandisena: §30. 58. Aṃ byañjane niggahitaṃ (153). El primero es el número secuencial de Kaccāyana — el que usamos para citar (§30) y el que fija el enlace permanente de cada sutta. El segundo es el número correspondiente en Padarūpasiddhi; el que va entre paréntesis, el de Saddanīti-Suttamālā, ausente en algunos suttas.Each sutta carries three numbers, as in Nandisena's edition: §30. 58. Aṃ byañjane niggahitaṃ (153). The first is Kaccāyana's sequential number — the one we cite by (§30) and the one that fixes each sutta's permanent link. The second is the corresponding number in Padarūpasiddhi; the one in parentheses is that of Saddanīti-Suttamālā, absent in some suttas.
