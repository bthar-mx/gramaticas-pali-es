260. 277. Sabbassa so dāmhi vā (508)

[Sabbassa + so + dāmhi + vā = 4 voces]

Sabba icc etassa sakārādeso hoti vā dāmhi paccaye pare.

Sadā, sabbadā.

Opcionalmente, cuando sigue ‘dā’, [hay] ‘sa’ de “sabba”.
Opcionalmente, cuando sigue el sufijo ‘dā’, “sabba” se sustituye por ‘sa’.
Ejemplos
  1. Sadā = sabba + dā (‘dā’ se usa con el significado de la séptima inflexión para indicar tiempo (§257); “sabba” se sustituye por ‘sa’ (§260)).
  2. Sabbadā = sabba + dā (‘dā’ se usa con el significado de la séptima inflexión para indicar tiempo (§257)).

Sin las notas al pie: están en la tarjeta del capítulo.
