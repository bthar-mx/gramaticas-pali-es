220. 74. Sesato lopaṃ ga si pi (447)

[Sesato + lopaṃ + gasi + api = 4 words]

Tato niddiṭṭhehi liṅgehi sesato ga si icc ete lopam āpajjante.

Bhoti itthi, sā itthī. Bho daṇḍi, so daṇḍī. Bho sattha, so satthā. Bho rāja, so rājā.

Sesato ti kimatthaṃ? Puriso gacchati.

Ga-sī ti kimatthaṃ? Itthiyā; satthussa.

After the remaining ones, ‘ga’ and ‘si’ are also elided.
After the remaining bases that have been shown, ‘ga’ and ‘si’ are elided.
Examples
  1. Itthi = itthī + si (‘si’ is named ‘ga’ (§57); ‘ī’ is named ‘pa’ (§59); ‘ī’ is shortened (§245); ‘ga’ is elided (§220)).
  2. Itthī = itthī + si (‘si’ is elided (§220)).
  3. Daṇḍi = daṇḍī + si (‘si’ is named ‘ga’ (§57); ‘ī’ is named ‘jha’ (§58); ‘ī’ is shortened (§245); ‘ga’ is elided (§220)).
  4. Daṇḍī = daṇḍī + si (‘si’ is elided (§220)).
  5. Sattha = satthu + si (‘si’ is named ‘ga’ (§57); ‘u’ of “satthu” becomes ‘ā’ (§244); ‘ā’ is shortened (§246); ‘ga’ is elided (§220)).
  6. Satthā = satthu + si (‘u’ of “satthu” becomes ‘ā’ (§199); ‘si’ is elided (§199)).
  7. Rāja = rāja + si (‘si’ is named ‘ga’ (§57); ‘a’ becomes ‘ā’ (§244); ‘ā’ is shortened (§246); ‘ga’ is elided (§220)).
  8. Rājā = rāja + si (‘si’ is substituted by ‘ā’ (§189); ‘a’ is elided (§83)).

What is the purpose of saying “after the remaining ones”? [This sutta does not apply when there are no remaining bases, such as in:] Puriso gacchati.

What is the purpose of saying “‘ga’ and ‘si’”? [This sutta does not apply when ‘ga’ or ‘si’ do not follow, such as in:] itthiyā; satthussa.
